## 📸 The Workstation Experience
Unlike traditional template portfolios, this site functions as a physical desk layout.
* **Focus Mode Interactivity:** Moving away from standard text cards, the workspace features a "Click-to-Expand" modal layout powered by shared element transitions.
* **The Hobbyist Grid:** Displays a mix of software logic, engineering workflows, and creative mediums—ranging from Python automation to 3D spatial design.

## 🚀 Local Development Setup

To run this workbench on your local machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/YOUR_USERNAME/my-portfolio.git](https://github.com/YOUR_USERNAME/my-portfolio.git)
   cd my-portfolio

```

2. **Install dependencies:**
```bash
npm install

```


3. **Run the development server:**
```bash
npm run dev

```


Open [http://localhost:3000](http://localhost:3000) with your browser to view the desk.
4. **Verify production readiness (Build Check):**
```bash
npm run build

```

## 📈 Security & Architecture Philosophy

* **Static Optimization:** The backend architecture is strictly optimized for fast edge delivery, utilizing Next.js layout structures while offloading data manipulation directly to client-side interactivity to maximize runtime speed.
* **Clean Dependency Layer:** Heavy middleware blocks were systematically decoupled to protect against loading bottlenecks, keeping page load-speeds sub-millisecond for professional technical review.
